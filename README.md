## ⚡ Sobre mí

Me interesa la tecnología, el diseño digital y el mundo gaming. Estoy construyendo mis bases en desarrollo web, empezando por HTML y avanzando paso a paso hacia sitios más completos, visuales y adaptables.

- 🎯 **Enfoque actual:** practicar HTML y crear páginas bien estructuradas.
- 🧩 **Mi objetivo:** aprender CSS y JavaScript para construir experiencias web interactivas.
- 🎮 **Inspiración:** interfaces de videojuegos, estética futurista y tecnología.
- 🛠️ **Mi forma de avanzar:** aprender haciendo, probar ideas y mejorar cada proyecto.
